# Embedded HTML Fonts

`mdf` vendors JetBrains Mono variable webfonts for self-contained HTML output.

- Upstream project: https://github.com/JetBrains/JetBrainsMono
- Upstream font files:
  - `fonts/webfonts/JetBrainsMono[wght].woff2`
  - `fonts/webfonts/JetBrainsMono-Italic[wght].woff2`
- Upstream license: `OFL.txt`

These assets are embedded into generated HTML by default. HTML can also opt
into the existing embedded Hack Nerd Font bundle instead.
